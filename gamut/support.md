# Gamut — Support

**Email:** viktoriia.seliver@gmail.com — please put "Gamut" in the subject.

### Common questions

**The import picker shows no screenshots.** Any screenshot of a three-column profile grid works — it does not have to be tagged as a screenshot by the system. Pick it from "All Photos".

**I bought Pro but the app says I'm on the free plan.** Open *More → Restore purchases*. Purchases are tied to your Apple ID; if Pro was bought under another one, sign in with it.

**I want my data out.** The Gamut folder is visible in the Files app — copy it to iCloud Drive. Everything the app knows is in there.

**Something got in my way and I want to show you what happened.** The app keeps a journal of what it does, in a plain text file on your phone — no names, no photos, no typed text. Open *Settings → Journal → Share the journal* and send it along with your message. It makes "it did something odd here" checkable instead of guesswork. If you would rather it kept nothing, switch the journal off on the same screen.

**Something looks broken in another language.** Every string in the app is translated into English, French and Russian and checked by tests; if you see the wrong language, tell us which screen.

### Assistance (FR)

Écrivez à viktoriia.seliver@gmail.com avec « Gamut » en objet. Achat Pro non reconnu : *Plus → Restaurer les achats*. Vos données : le dossier Gamut est visible dans l'app Fichiers. Pour signaler un problème : *Réglages → Journal → Partager le journal* — un fichier texte sans noms ni photos, que l'app garde sur votre téléphone.

### Поддержка (RU)

Пишите на viktoriia.seliver@gmail.com с темой «Gamut». Pro не узнался — *Ещё → Восстановить покупки*. Свои данные — папка Gamut в приложении «Файлы». Если что-то мешало — *Настройки → Журнал → Поделиться журналом*: приложение держит на телефоне текстовый файл своих действий, без имён и фотографий. С ним «оно повело себя странно» становится проверяемым.
