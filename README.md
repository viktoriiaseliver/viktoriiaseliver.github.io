# Страницы приложений

Публичный репозиторий ровно под одно: политику приватности и поддержку.
Их требует App Store Review (5.1.1) и Beta App Review, а адрес должен быть
живым и открываться без входа. Исходники приложений остаются закрытыми —
здесь только страницы.

## Почему именно такое имя репозитория

Репозиторий называется `viktoriiaseliver.github.io` — это **сайт
пользователя** GitHub Pages, он публикуется по адресу
`https://viktoriiaseliver.github.io/`. Папка `timer-app/` внутри отдаёт
`https://viktoriiaseliver.github.io/timer-app/privacy.html` — **ровно те
адреса, которые уже зашиты в приложении** (`Shared/AppInfo.swift`,
`AppLinks`). Менять в коде ничего не нужно.

Если когда-нибудь понадобится открыть сам репозиторий `timer-app` и
включить в нём Pages — он перехватит путь `/timer-app/` на себя. Тогда
папку отсюда можно удалить.

## Языки: язык в адресе, старый адрес — развилка

У приложений много языков, у страниц было мало. Теперь у каждой страницы
язык стоит в пути, а старый адрес без языка остался жить развилкой:

```
/timer-app/privacy.html      ← этот адрес в App Store Connect и в коде
/timer-app/en/privacy.html
/timer-app/ru/privacy.html
```

Развилка — не заглушка. В `<head>` у неё скрипт, который смотрит
`navigator.languages` и уводит на свой язык **до отрисовки**, поэтому
подмигивания не видно. Тот, у кого JavaScript выключен, видит страницу
из двух-трёх ссылок с подписями на своих языках. Ни один старый адрес
не умер и не редиректится на 404 — это важнее удобства: мёртвая ссылка
на политику это отказ по 5.1.1.

Какие языки где:

| Папка | Приложение | Языки страниц | Языки самого приложения |
|---|---|---|---|
| `timer-app/` | Five More Minutes | en, ru | 9 (en, ru, de, fr, es, it, ja, pt-BR, ar) |
| `gamut/` | Gamut | en, ru, fr | 3 (ru, en, fr) |
| `togo/` | Того | en, ru | 1 (ru) |

Страницы Того на английском появились раньше, чем английский в самом
приложении: политику открывает App Review, и открывает по-английски.

**Добавить язык** — положить рядом папку `xx/` с теми же файлами и
дописать язык в трёх местах: в переключателе `<p class="lang">` на
каждой странице, в `<link rel="alternate" hreflang>` и в скрипт развилки.
У Того это делается в одном месте — `Tools/build_site.py`, список `LANGS`.

`en` выбран языком по умолчанию (`hreflang="x-default"`): браузер
с любым третьим языком уходит на него.

## Что здесь лежит

| Путь | Что это |
|---|---|
| `index.html` | развилка по языку, корень сайта |
| `en/`, `ru/` | список всех приложений, по странице на язык |
| `timer-app/`, `gamut/`, `togo/` | по папке на приложение |
| `style.css` | общий стиль, светлая и тёмная тема |

Внутри папки приложения: развилки в корне (`privacy.html`, `support.html`,
`index.html`) и сами страницы в `en/`, `ru/`, `fr/`.

`timer-app/privacy-en.html` и `support-en.html` — старые адреса английских
страниц, опубликованные 3 сентября 2026. Они не удалены, а ведут на новое
место: адрес мог куда-то разойтись, а стоит он дешевле, чем 404.

Все страницы — обычный HTML, без шаблонизатора. Jekyll на GitHub Pages
работает, но ничего не собирает: markdown-страниц здесь больше нет
(до 21 сентября 2026 страницы Gamut были `.md` и, из-за отсутствия
`_layouts`, публиковались без `<head>` — то есть вообще без стиля).

Файла `.nojekyll` здесь нет. Он и не нужен: Jekyll отдаёт `.html`
как есть. Но помнить про Jekyll всё равно надо в одном: **файл, имя
которого начинается с `_`, он не публикует**, и делает это молча.
`_style.css` однажды уже не выложился — страницы всех приложений
открывались без оформления, а по коду 200 это было незаметно.

## Того

Страницы Того **собираются из приложения**, а не пишутся здесь: их делает
`Tools/build_site.py` в репозитории Того. Русский текст — из
`LegalScreens.swift`, того же, который человек читает в настройках; второй
копии нет намеренно. Английский перевод лежит отдельно, в
`Tools/site_en.py`, и это как раз вторая копия — потому что в приложении
английского пока нет. Разойтись молча она не может: скрипт считает
отпечаток русского текста, и правка без правки перевода валит сборку.

Поэтому править файлы в `togo/` руками бесполезно — их перезапишет
следующая публикация. Менять надо в приложении, а сюда класть командой
`make site`.

## Проверить перед публикацией

Все ссылки внутри сайта — относительные, и битую видно только руками.
Быстрая проверка:

```bash
python3 - <<'PY'
import os, re, sys
bad = 0
for root, dirs, files in os.walk("."):
    dirs[:] = [d for d in dirs if d != ".git"]
    for f in files:
        if not f.endswith(".html"):
            continue
        path = os.path.join(root, f)
        text = open(path, encoding="utf-8").read()
        urls = re.findall(r'(?:href|src)="([^"]+)"', text)
        urls += re.findall(r'location\.replace\("([^"]+)"\)', text)
        for url in urls:
            if url.startswith(("http", "mailto:", "#", "//")):
                continue
            if not os.path.exists(os.path.normpath(os.path.join(root, url))):
                print("битая:", path, "→", url)
                bad += 1
print("битых нет" if not bad else f"битых: {bad}")
sys.exit(1 if bad else 0)
PY
```

## Как опубликовать (один раз)

1. Создать на GitHub **публичный** пустой репозиторий с именем
   `viktoriiaseliver.github.io` (без README — он уже здесь).
2. В этой папке:

   ```bash
   git remote add origin git@github.com:viktoriiaseliver/viktoriiaseliver.github.io.git
   git push -u origin main
   ```

3. Pages для сайта пользователя включаются сами. Через минуту проверить:

   ```bash
   curl -s -o /dev/null -w "%{http_code}\n" https://viktoriiaseliver.github.io/timer-app/privacy.html
   ```

   Должно быть `200`.
